# EyeTimeTracker 用眼时间记录

EyeTimeTracker 是一个轻量级的用眼时间统计工具，用来记录 Windows 电脑和 Android 手机上真实的屏幕使用时间。它的目标不是简单统计开机时间，而是帮助用户看清每天、每周、每月在多块屏幕上的注视时间，并在接近设定时长时提醒休息。

当前项目包含 Windows PC 端和 Android 端，已经支持同一局域网内的一台电脑和一台手机配对同步。同步后，两端会显示合并并去除重叠后的统计结果。

## 当前状态

- Windows PC 端：可日常运行，支持主界面、统计页、提醒弹窗、系统托盘菜单、开机启动开关。
- Android 端：可日常运行，支持前台服务、主界面、统计页、提醒设置、横幅通知和声音提醒。
- WiFi 局域网同步：支持一台 PC 和一台 Android 手机配对、断开、自动重连和数据同步。
- 双端统计：同步后今日、昨日、本周、本月、统计页图表会尽量使用同一套合并数据。
- 重叠去重：电脑和手机同一时间段都在使用屏幕时，总用眼时间只计算一次。
- 多语言基础：已经建立 `i18n` 文案结构，后续可继续完善英文界面和语言切换。

## 主要功能

- 今日、昨日、本周、本月用眼时间统计。
- 自定义提醒时间，支持一天内多次提醒。
- 电脑端根据键盘、鼠标动作和媒体播放状态计时。
- 安卓端按亮屏使用时间计时，不把息屏播放计入用眼时间。
- 统计页展示 24 小时分布、本周用眼、月度趋势、连续使用分布和护眼表现摘要。
- 24 小时图按电脑和手机来源分色显示，并标出 0、6、12、18 点。
- 手机与电脑配对后，统计来源比例会显示电脑/手机占比。
- 安卓提醒可使用系统横幅通知、声音和振动。
- PC 提醒弹窗带声音提示。
- PC 系统托盘菜单使用应用内统一视觉风格。

## 统计规则

### PC 端

PC 端不统计单纯开机时间，而是按活动状态计时：

- 最近一段时间内有键盘或鼠标动作时，计入用眼时间。
- 检测到媒体播放时，计入用眼时间。
- 几秒到十几秒的短暂停顿通常不会立刻打断一次连续用眼。
- 长时间无输入且无媒体播放时，暂停计时。

### Android 端

Android 端统计更接近手机屏幕亮起后的使用时间：

- 屏幕亮起时，视为正在使用手机屏幕。
- 屏幕关闭后，停止计入用眼时间。
- 息屏播放音频不计入用眼时间。
- 不使用前置摄像头判断用户是否真正注视屏幕，因此统计结果是对亮屏使用的估算。

### 双端合并

- 电脑和手机都按统一的 10 秒时间格记录使用情况。
- 同一个 10 秒时间格内，只要任意一端使用屏幕，就计入总用眼时间。
- 如果两端同时使用屏幕，这个时间格只算一次，不重复累计。
- 电脑/手机来源比例会根据每端贡献的时间估算，可能有少量误差。

## 配对与同步

当前同步方式是 WiFi 局域网同步，不需要登录账号。

基本流程：

1. 手机和电脑连接到同一个可互通的局域网。
2. 手机端生成配对码。
3. PC 端输入手机上显示的配对码。
4. 配对成功后，两端保存配对关系，后续会尝试自动重连。
5. 同步时会使用配对生成的密钥验证消息，避免陌生设备写入数据。

注意：

- 当前主要支持一台 PC 和一台 Android 手机。
- 如果路由器隔离了 2.4G 和 5G，或者开启了访客网络隔离，两端可能无法互相发现。
- 更换 WiFi 后，只要两端重新进入可互通的同一局域网，后续目标是自动重连；部分网络环境仍需要继续优化。
- 互联网云同步、账号系统、多设备同步还未完成。

## 提醒规则

- 未配对时，PC 和 Android 可各自使用本机提醒设置。
- 配对后，提醒设置以手机为主，PC 会跟随手机同步。
- 如果两端都正在计时，达到提醒条件时两端都可以弹出提醒。
- 修改提醒时间后，不会补弹修改前已经跨过的提醒点，而是从当前累计时间继续等待下一个新的提醒点。
- “反复提醒”关闭时，一天内只提醒一次；打开时，每达到一次设定时间就提醒一次。

## 健康颜色

今日用眼时间会根据使用时长改变颜色：

- 6 小时以内：绿色。
- 6 到 8 小时：黄色。
- 大于 8 小时：红色。

这些颜色只用于提醒用户关注使用强度，不代表医学诊断。

## 构建与测试

### Windows PC 端

需要 .NET 8 SDK。

```powershell
dotnet build src\EyeTimeTracker.App\EyeTimeTracker.App.csproj -c Release
dotnet test tests\EyeTimeTracker.Tests\EyeTimeTracker.Tests.csproj -c Release
```

### Android 端

需要安装 Android SDK、JDK，并配置用户环境变量：

- `ANDROID_SDK_ROOT`
- `JAVA_HOME`

构建 APK：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File android\EyeTimeTrackerAndroid\build-android.ps1
```

生成的调试 APK 位于：

```text
outputs/android/EyeTimeTrackerAndroid-debug.apk
```

安装到已连接并开启 USB 调试的手机：

```powershell
adb install -r outputs\android\EyeTimeTrackerAndroid-debug.apk
```

## 当前限制

- 当前 WiFi 同步主要面向一台 PC 和一台 Android 手机。
- 还没有账号系统、云同步、iOS 端和 macOS 端。
- Android 端没有使用前置摄像头判断是否真正注视屏幕。
- 应用不能判断用户是否真的完成了远眺休息，只能根据停止使用屏幕推断休息时间。
- 旧版本只保存汇总数据的日期，无法做到完全精确的跨端重叠去重。
- Android 工程目前仍使用轻量脚本直接构建，尚未迁移到 Gradle/Android Studio 标准项目结构。
