# WiFi 局域网同步说明

本文说明当前版本的 PC 与 Android 同步方式。

## 当前支持范围

- 支持一台 Windows PC 和一台 Android 手机配对。
- 支持同一局域网内同步用眼时间和提醒设置。
- 支持断开后重新连接。
- 支持手机离开 WiFi 后显示离线，回到可互通网络后尝试自动重连。

暂不支持：

- 多台手机。
- 多台 PC。
- 互联网云同步。
- 账号登录。
- iOS 和 macOS。

## 配对方式

1. 手机端进入配对流程并生成配对码。
2. PC 端输入手机上显示的配对码。
3. 配对成功后，两端保存设备关系和共享密钥。
4. 后续同步消息会使用共享密钥验证。

用户不需要手动填写电脑 IP 地址。发现和连接由应用在局域网内完成。

## 统计合并方式

双端统一使用 10 秒时间格记录屏幕使用情况。

合并规则：

- 同一个 10 秒时间格内，只要任意一端使用屏幕，就计入总用眼时间。
- 如果电脑和手机同时使用屏幕，这个时间格只算一次。
- 电脑/手机来源比例根据各自贡献的使用时间计算，可能会有少量误差。
- 单小时统计最多显示 60 分钟。

这种方式可以让手机和电脑的总用眼时间保持一致，也避免两块屏幕同时使用时重复累计。

## 提醒设置同步

- 未配对时，PC 和 Android 使用各自本机提醒设置。
- 配对后，手机端作为提醒设置主端。
- 手机修改提醒时间后，PC 会跟随同步。
- PC 端仍保留提醒设置入口，因为未配对时 PC 需要独立可用。
- 已配对时，PC 提醒设置窗口会提示用户到手机端修改。

## 提醒弹出规则

- 如果只有一端正在计时，由正在计时的一端提醒。
- 如果两端都正在计时，两端都可以提醒。
- 修改提醒时间后，不补弹修改前已经跨过的提醒点，而是从当前累计时间继续等待下一个新提醒点。
- 关闭“反复提醒”后，一天内只提醒一次。
- 打开“反复提醒”后，每达到一次设定时间就提醒一次。

## 已知网络限制

同步要求两端在可互通的局域网内。以下情况可能导致无法自动同步：

- PC 和手机虽然连接同一个路由器，但 2.4G 和 5G 被路由器隔离。
- 手机连接访客 WiFi。
- 路由器关闭了局域网设备互访。
- Windows 防火墙阻止 PC 监听或接收连接。
- Android 后台联网被系统省电策略限制。

如果两端明明在同一个 WiFi 下但无法连接，应优先检查路由器隔离和防火墙设置。

## 与未来云同步的关系

当前局域网同步已经使用“设备身份、共享密钥、时间片段合并、重叠去重”的思路。未来增加账号和云同步时，应继续沿用这些核心规则，避免重新定义统计口径。
